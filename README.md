# Laboratório MODAL

Página institucional do Laboratório de Modelagem Matemática e Algoritmos, Coordenação de Ciência da Computação, UFMA (São Luís).

Site: https://glaubosclimaco.github.io/laboratorio-modal/

Trilha de entrada em Pesquisa Operacional: https://glaubosclimaco.github.io/onboarding-po/

## O que tem aqui

- `index.html`: a página completa, um arquivo só. É o que o GitHub Pages publica.
- `img/`: logotipos do laboratório, da UFMA e das parcerias.

## Como atualizar

O site é um único arquivo HTML, sem dependências nem build. Edite `index.html`, faça commit na branch `main` e o GitHub Pages republica sozinho em cerca de um minuto.
